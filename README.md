# StompEngine
Game engine for strategic multiplayer games.

## Get started
Clone repo with 

`git clone --recurse-submodules git@github.com:N1kla3/StompEngine.git`

Build project with

`python Scripts/builder.py`

For fresh build use 

`python Scripts/builder.py --fresh`

For release build use

`python Scripts/builder.py --build=release`

Build presets are in CMakePresets.json
